# v0.7.0 后采用 GPL-3.0-only 许可证

以现有 `power4j` 仓库身份维护的 FlowLens 当前开发版本，以及 v0.7.0 之后发布的源代码和预编译二进制，仅使用 GPL-3.0-only 许可证。项目选择强 copyleft 许可证，以确保后续分发的修改版本继续向接收者提供相同的源代码使用、修改和再分发自由；仓库使用未经修改的 GNU GPL v3 全文作为 `LICENSE`，并在 Cargo SPDX 元数据和中英文使用者文档中保持一致声明。

本决定取代 ADR-0010，但不追溯变更已有发布：v0.7.0 及更早版本继续适用各自标签和发布制品中所附的 Apache-2.0 许可证。项目以 `power4j` 作为公开版权署名，以 `power4j@outlook.com` 作为联系方式；各贡献者署名继续由 Git 历史记录保留。
