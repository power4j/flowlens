# 固定默认主题选择

FlowLens 在省略 `--theme` 时固定使用 Signal Deck，不再读取 `NO_COLOR`、`COLORTERM` 或 `TERM` 来推断主题。主题是用户选择的完整语义呈现方案，而终端环境变量不能可靠地表达用户希望采用的主题；固定默认值也使同一启动命令在不同终端中得到一致的界面。

`--theme` 提供的任意名称仍按通常顺序解析：先匹配已注册内置主题，再匹配显式路径，最后从用户主题目录读取短名称对应的 JSON。因此 `--theme auto` 不再是保留策略名，而是普通名称；在当前目录没有同名内置主题时，它读取用户主题目录中的 `auto.json`，缺失时报告普通主题文件错误。设置浮层只循环已注册内置主题和启动时成功加载的外部主题，选择仅保存在内存中。

本决定取代 ADR-0002 中依据终端能力自动选择主题的决定。它不改变四个内置主题、`truecolor`、`ansi16` 和 `mono` 的验证规则，也不改变 ANSI 16 和 Mono 的渲染和终端色槽行为。
